



Codsoft Codes - Internship Projects

This repository contains the projects I developed during my internship at Codsoft. Each project is implemented in Python and demonstrates different aspects of software development and problem-solving. Below is a list of the projects included:

Projects

1. Railway Ticket Booking System

A simple command-line interface (CLI) project that simulates a railway ticket booking system.

Users can book, cancel, and view available tickets.

Key Features:

User-friendly interface for booking tickets.

Option to cancel or modify existing bookings.

Displays available seats for each train.


Tech stack: Python



2. Recommendation System

A machine learning-based recommendation system.

It provides personalized recommendations based on user preferences or history.

Key Features:

Data preprocessing to filter and process user inputs.

Collaborative filtering or content-based filtering to generate recommendations.


Tech stack: Python, Machine Learning libraries (e.g., NumPy, pandas, scikit-learn)



3. Tic-Tac-Toe Game

A two-player Tic-Tac-Toe game built using Python.

Players can play against each other, with the system handling turns and checking for a winner.

Key Features:

Simple game logic with a 3x3 grid.

Checks for winning conditions after each move.

Option to restart the game.


Tech stack: Python




How to Run the Projects

1. Railway Ticket Booking System

Clone the repository and navigate to the RailwayTicketBookingSystem directory.

Run the following command to start the program:

python railway_ticket_booking.py



2. Recommendation System

Clone the repository and navigate to the RecommendationSystem directory.

Run the following command to start the program:

python recommendation_system.py



3. Tic-Tac-Toe Game

Clone the repository and navigate to the TicTacToe directory.

Run the following command to start the game:

python tic_tac_toe.py




Requirements

Python 3.x

Libraries required (for the Recommendation System):

NumPy

pandas

scikit-learn
